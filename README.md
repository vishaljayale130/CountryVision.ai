# 🌎 CountryVision AI

CountryVision AI is a colorful and modern country information explorer.

Simply enter a country name and explore useful information such as:

- 🏳️ Country Flag
- 🏛️ Capital
- 👥 Population
- 📐 Area
- 💰 Currency
- 🗣️ Languages
- 🌍 Continent
- 🗺️ Geography
- 🕐 Time Zones
- 🌐 Internet Domain
- 📞 Calling Code
- 🚗 Driving Side
- ⭐ Favorite Countries
- 🕘 Recent Searches
- 🌙 Dark / Light Mode
- 🤖 AI-style Country Summary
