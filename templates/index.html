ABOUT THE PROJECT

Explore the world, one country at a time.

CountryVision AI is a beginner-friendly country exploration website created using Python, Flask, HTML, CSS and JavaScript. Enter a country name and the website retrieves available country information and presents it in an easy-to-understand interface.
